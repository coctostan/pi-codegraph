# Learnings — Issue #075

- **Centralization paid for itself.** Keeping every trust-header decision inside `finalizeReadOnlyOutput` (rather than per-tool) meant the new flag required exactly one runtime branch plus three thin schema additions. The three tool execute sites each changed by one extra argument only.
- **`params.suppressTrustHeader === true` is a small but important choice.** Strict triple-equals keeps `absent`, `undefined`, and `false` on a single "baseline" branch, which is what made AC 7's byte-identity guarantee trivial to test (a single `explicit === omitted` assertion per tool).
- **The helper contract is narrower than it looks.** `stripTrustHeader` only strips when line 1 starts with `status: ` and line 2 starts with `evidence: `. The current emitter always includes `stale-files:` on line 2 as well, but the helper does not enforce that. This is defensive (idempotence, malformed-input no-op) but would drift silently if the header format ever changed — worth revisiting if `formatTrustHeader` grows a fourth required line.
- **Interaction tests were the highest-value coverage.** Schema + single-tool tests passed easily, but the interactions file (indexing-failed note, `_meta` footer, fresh/stale body preservation, `false === omitted`) caught the real risk: accidentally reordering header stripping with the indexing-failed prepend or the devmeta append.
- **Bun `expect.toBe` comparisons on fresh-vs-suppressed output are a cheap way to lock "idempotent with existing suppression" invariants.** AC 6's fresh-graph requirement became a one-liner assertion instead of a re-encoded expected string.
- **Verify artifacts beat reruns.** The saved `verify.md` included the impact-dependents list (`piCodegraph` via four `register` helpers) with inline confirmation that each dependent file was exercised by the new tests. That made the code-review phase fast because the breaking-change surface was already documented.
- **External tooling can disappear mid-session.** `/codex-review` and `/codex-adversarial-review` were unavailable (Codex CLI auth expired, no `/codex-adversarial-review` binary). The review still completed via the local `code-reviewer` subagent plus direct `impact`/`symbol_graph` queries — worth keeping a fallback explicitly in the review rubric.
